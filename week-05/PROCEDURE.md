# Week 05 - State methods

## Aim

Put state recognition and state transition logic into reusable Java methods.

## Procedure

1. Implement `isKnownState` for the three fixture labels.
2. Implement `nextState` for the `READY` transition.
3. Invoke both using a single deterministic fixture.
4. Compile, run, and compare output proof.

## Scope boundary

The methods operate only on fictitious classroom labels, not on a booking or property-management system.
