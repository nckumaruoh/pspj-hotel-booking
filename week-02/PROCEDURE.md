# Week 02 - Validate fixture room codes

## Aim

Accept only four invented classroom codes before printing a state label.

## Procedure

1. Validate `R102` with a small regular-expression rule.
2. Show its fixed classroom state label.
3. Reject the deliberately invalid fixture `R999`.
4. Compile, run, and compare the exact output.

## Scope boundary

The code is an abstract exercise identifier, not a physical room, guest record, or availability lookup.
