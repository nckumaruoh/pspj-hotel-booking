# Week 04 - Loop through fixtures

## Aim

Use a loop to inspect four fixed classroom room-state entries.

## Procedure

1. Place four abstract codes and matching state labels in arrays.
2. Traverse each index with a `for` loop.
3. Print one deterministic state line per fixture.
4. Verify the generated text against `OUTPUT.txt`.

## Scope boundary

All values are synthetic learning fixtures and do not disclose or query any real premises or occupancy.
