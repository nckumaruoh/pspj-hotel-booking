# Week 06 - Arrays and search

## Aim

Use parallel arrays to perform a deterministic search over four classroom fixtures.

## Procedure

1. Store abstract codes and state labels in matching arrays.
2. Implement a linear-search method.
3. Search once for an existing fixture and once for a missing fixture.
4. Run the program and compare with `OUTPUT.txt`.

## Scope boundary

The search is entirely local to invented test data and cannot show real room availability.
