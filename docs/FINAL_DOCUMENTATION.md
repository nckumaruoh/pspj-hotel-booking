# Classroom Room-State Simulator - Final Documentation

## Purpose

This repository is a Week 01 to Week 12 PSPJ learning pathway. Each increment advances one Java topic using deterministic, invented room-state fixtures.

## Safety and scope

`R101` through `R104` and their labels are artificial classroom codes. This project is not a lodging, hotel, booking, guest, payment, address, date, availability, or hospitality-operations system.

## Evidence structure

Each `week-XX` directory includes Java source, `PROCEDURE.md`, `TRACE.md`, and `OUTPUT.txt`. Week 11 generates and commits a fictional CSV. Week 12 provides the collection-and-stream final report.

## Verification

Compile and run each week in isolation, then compare its exact console output with that week's `OUTPUT.txt`. The repository's twelve tags preserve the progressive development record.
