# Week 03 - State-transition decision

## Aim

Use a conditional decision to move one fictional room-state fixture from `READY` to `IN_USE`.

## Procedure

1. Start `R101` in the `READY` fixture state.
2. Apply a conditional expression representing the learning rule.
3. Print the before state, rule, and after state.
4. Compile, run, and verify `OUTPUT.txt`.

## Scope boundary

This transition is a programming example only; it makes no reservation and changes no real-world state.
