# Week 10 - Exception handling

## Aim

Catch an unsupported classroom state with a checked exception.

## Procedure

1. Define `InvalidRoomStateException`.
2. Use `ARCHIVED` as a deliberately unsupported fixture.
3. Throw and catch the exception locally.
4. Verify that the deterministic console report matches `OUTPUT.txt`.

## Scope boundary

This exception demonstration is isolated from any real accommodation or customer workflow.
