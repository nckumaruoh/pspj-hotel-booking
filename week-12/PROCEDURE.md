# Week 12 - Collections and final report

## Aim

Use an `ArrayList` and streams to count four fixed classroom state fixtures.

## Procedure

1. Create four `RoomFixture` objects in an `ArrayList`.
2. Use stream filters to count each of the three allowed state labels.
3. Print the final deterministic report.
4. Compile, run, and compare with `OUTPUT.txt`.

## Scope boundary

The final report is educational fixture analytics, not a real operational availability or occupancy report.
