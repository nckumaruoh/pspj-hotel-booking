# Week 07 - Modular edge-case checks

## Aim

Split code and state validation into separate methods and test rejected fixture cases.

## Procedure

1. Validate an empty code with `validCode`.
2. Validate an unsupported state with `validState`.
3. Print a pass condition only when both invalid fixtures are rejected.
4. Compile, run, and confirm exact output.

## Scope boundary

These checks protect a fictional exercise data set only.
