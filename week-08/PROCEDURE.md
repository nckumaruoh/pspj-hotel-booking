# Week 08 - Recursive state count

## Aim

Use a recursive method to count one designated state in a short fixture array.

## Procedure

1. Define four synthetic state labels with one `RESET_REQUIRED` entry.
2. Implement a base case at the end of the array.
3. Accumulate the matching-state count on recursive return.
4. Compile, run, and compare with `OUTPUT.txt`.

## Scope boundary

This counts teaching fixtures only; it is not an operational room-status report.
