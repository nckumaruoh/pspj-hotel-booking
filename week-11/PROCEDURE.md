# Week 11 - Fictional CSV fixture

## Aim

Write and read a local CSV file that contains four invented room-state fixtures.

## Procedure

1. Define a header and four synthetic rows in Java.
2. Write them to `room_state_fixture.csv` in this folder.
3. Read the file back and count its data rows.
4. Commit the generated CSV after verifying output.

## Scope boundary

The file contains only abstract teaching states; it has no lodging, guests, reservations, dates, or payment information.
