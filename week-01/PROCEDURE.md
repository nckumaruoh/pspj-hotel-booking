# Week 01 - Classroom state baseline

## Aim

Create a deterministic Java console baseline with invented room codes and state labels.

## Procedure

1. Define the simulator title and three fixed fixture codes.
2. Print an initial classroom state for `R101`.
3. Compile and run the Java class from this folder.
4. Compare the result with `OUTPUT.txt`.

## Scope boundary

This is a classroom state simulation, not a lodging, booking, guest, payment, address, date, or operational-availability system.
