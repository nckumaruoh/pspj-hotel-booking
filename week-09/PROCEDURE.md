# Week 09 - Object model

## Aim

Represent a classroom room-state fixture with a small Java class.

## Procedure

1. Define a `LearningRoom` class containing only a code and state.
2. Create two objects from invented fixtures.
3. Override `toString` to show object state in the console.
4. Compile, run, and compare the proof file.

## Scope boundary

The objects contain no guest, date, address, payment, or booking data.
